## Conclusão

O algoritmo desenvolvido realiza aproximadamente **59 a 95 operações de percurso** para 10 elementos. Sua complexidade é dominada pelo **Insertion Sort**, que é **O(n²)** no pior caso, mas pode ser **O(n)** quando os dados já estão ordenados. Para **n=10**, o desempenho é excelente, com poucas operações, pois o tamanho do array é pequeno.
